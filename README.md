## Workshop Description
In this workshop on **Multiverse Analyses**, Giulia will:

- Introduce attendees to the **multiverse concept** and explain why it matters,  
  especially in multilab contexts.  
- Discuss how the **multiverse approach** addresses researcher degrees of freedom  
  across labs.  
- Present how the **MB2P (Pupillometry) spin-off project** is implementing  
  a multiverse analysis approach using the data from the main MB2 study.
